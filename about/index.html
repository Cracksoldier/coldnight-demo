About

Hey, I’m Alex — a software engineer who spends most of the day thinking about distributed systems, developer tooling, and occasionally why CSS still surprises me.

This blog is where I write about things I figure out, things that took me longer than expected to understand, and patterns I find worth sharing. No algorithm, no schedule — just notes.

What I work on

I build backend infrastructure at a mid-size SaaS company. Most of my day-to-day involves Go, PostgreSQL, and Kubernetes, with occasional detours into TypeScript when the frontend team needs a hand.

Outside of work I contribute to a handful of open-source projects, mostly tooling and CLI utilities. I find small, focused tools more satisfying to build than large frameworks.

What you’ll find here

Posts lean technical but I try to keep them approachable. Topics cycle around:

  • Systems — databases, caching, queuing, observability
  • Git & workflow — how I organise code, review it, and ship it
  • Web — CSS, static sites, performance, the occasional deep dive into browser behaviour
  • Tools — editor config, terminal setup, scripts that save five seconds a hundred times a day

How this site is built

Built with Hexo and a custom dark theme called coldnight, written from scratch. Source is on GitHub. If you spot a bug or want to use the theme, open an issue.

Get in touch

The best way to reach me is on GitHub. I read everything but reply slowly.
